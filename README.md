# 视觉素材库原型

这是一个可直接用浏览器打开的静态网页原型，用于展示跨境商品视觉素材库。

## 文件结构

```text
.
├── index.html
├── assets/
│   └── reference-library.png
└── README.md
```

## 本地预览

直接双击 `index.html`，或在浏览器中打开该文件即可预览。

## 上传到 GitHub Desktop

1. 打开 GitHub Desktop。
2. 选择 `File` -> `Add Local Repository...`。
3. 选择本文件夹：`image-library-github-upload`。
4. 如果提示不是 Git 仓库，选择 `create a repository`。
5. 填写仓库名，例如 `image-library-prototype`。
6. 点击 `Publish repository` 上传到 GitHub。

## GitHub Pages

上传后可在 GitHub 仓库中开启 Pages：

1. 进入仓库的 `Settings`。
2. 打开 `Pages`。
3. Source 选择 `Deploy from a branch`。
4. Branch 选择 `main`，目录选择 `/root`。
5. 保存后等待 GitHub 生成访问链接。
